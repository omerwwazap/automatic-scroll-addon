# Auto Page Scroller Firefox Add-on

A Firefox browser extension that automatically scrolls web pages at a customizable speed. Perfect for reading manga, long articles, or any content that requires continuous scrolling.

## Features

- Adjustable scrolling speed via slider or keyboard shortcuts
- Ctrl+Shift+Up/Down to change speed
- Auto-stops at page bottom
- Persistent speed settings
- Clean, intuitive interface

### Direct Download (Recommended)

1. Download the extension from [here](https://addons.mozilla.org/firefox/downloads/file/4474332/995d368d364f4b1e86b2-1.2.1.xpi)
2. Firefox will automatically prompt you to install the extension
3. Click "Add" to complete installation

## Usage

1. Click the extension icon to open controls
2. Use slider to set scroll speed
3. Click "Start Scrolling" to begin
4. Use keyboard shortcuts for quick speed adjustments

## Development

- Built using Firefox WebExtensions API
- Uses Manifest V3
- ES6+ JavaScript
- No external dependencies
